# Rongqi Yu 个人求职网站（GitHub Pages）

网站结构
- index.html：首页（介绍、7 个项目卡片、项目视频、学历经历、技能、联系方式）
- projects/*.html：每个项目的详情页（问题、流程、可视化、结果、视频）
- assets/img/：所有图表
- assets/video/：7 个项目讲解视频（mp4，带字幕，无声音）
- assets/Yu_Rongqi_CV.pdf：简历（含手机号，介意的话替换掉）

发布步骤
1. GitHub 新建公开仓库，名字必须是 yuromhqi63.github.io
2. 仓库页面 Add file → Upload files，把本文件夹里的所有内容（index.html、projects、assets、README.md）拖进去，Commit
   （网页上传单次最多 100 个文件，本网站文件数在这以内）
3. Settings → Pages → Branch 选 main / (root) → Save
4. 等 1–2 分钟，访问 https://yuromhqi63.github.io
