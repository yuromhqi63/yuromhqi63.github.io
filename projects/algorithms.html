01 / The question

Before reaching for libraries, I wanted to be able to run the core algorithms by hand: choose a split from entropy or Gini, find a maximum-margin hyperplane, and multiply conditional probabilities. Each exercise was solved on paper and then reproduced in Python so the two can be compared.

02 / Process

How I built it

  1. 01

    Decision tree with entropy (ID3)

    Seven building materials, four attributes. Root entropy 0.985 bits; information gain is 0.700 for Shape, 0.522 for Color and 0.128 for Size, so the tree splits on Shape first, and pillars are split again on Color. A small green pillar is classified as usable.

  2. 02

    Gini index vs classification error

    The 14-day weather data built twice. With Gini (root 0.459), Outlook gives the lowest weighted impurity (0.343) and wins. With classification error, Outlook, Windy, Temperature ≤ 84 and Humidity ≤ 82.5 all tie at 0.286: error is too coarse to tell splits apart, which is why Gini or entropy are preferred.

  3. 03

    Rules from a tree

    Turned each root-to-leaf path of a given tree into an IF-THEN rule.

  4. 04

    Linear SVM

    Six labelled points. The support vectors are (2,2), (4,1) and (3,3), giving w = (2/3, 4/3), b = −5, i.e. the line x + 2y = 7.5 with margin 2/‖w‖ ≈ 1.34. scikit-learn returns the same answer.

  5. 05

    Naive Bayes

    Twenty animals, four yes/no features. For (gives birth, cannot fly, lives in water, no legs): P(x|mammal)P(mammal) = 0.0210 vs 0.0027 for non-mammals, so it is a mammal (think whale or dolphin).

  6. 06

    Similarity measures and missing data

    Cosine, correlation, Euclidean and Jaccard for three vector pairs: (1,1,1,1) vs (2,2,2,2) has cosine 1 but Euclidean distance 2 and undefined correlation, a reminder that each measure answers a different question. Also when to drop, impute or predict missing values.
